Efficiency

Measured, not claimed

2,661 tokens minimal per-call overhead*

* system prompt + all 15 tool schemas, measured live against the deepseek-v4-flash API (usage.prompt_tokens on a trivial reply).

  • Minimal task-oriented system prompt — rewritten around completing work with tools, not chat pleasantries
  • CJK-aware token estimator — zero-dependency pre-send budgeting for compaction decisions
  • Context compaction — summarizes history instead of dropping it; keeps tool/assistant pairs valid for the API
  • Tool-result truncation — huge command output is clipped before it re-enters the context window
  • Prompt caching — stable system + tools hit the cache across turns
  • Zero runtime deps for the kernel — ink + react exist only for the interactive TUI

71/89 on Terminal-Bench with DeepSeek V4 Flash: what token efficiency buys you

RingZero engineering notes · 2026-08-06

Agent scores are usually bought with compute. This run bought an 80% pass rate on Terminal-Bench 2.0 with a $0.14 / $0.28 per-million-token model — 164.6M input and 3.4M output tokens of DeepSeek V4 Flash for the whole 89-task benchmark, retries included.

80%pass rate (71/89)
164.6Minput tokens total
3.4Moutput tokens total

The number that matters most is the 2,661-token fixed overhead: that is everything RingZero sends before your actual work starts — system prompt plus fifteen tool schemas. Most of the surface area is tool definitions, and most of those are optional; a headless task run drops the interactive ones and ships even less. Every token above that baseline is spent on the task itself.

That budget discipline shows up across the run. Tool results are truncated before they re-enter context, so a 500 KB log line cannot silently quadruple the next call. Compaction summarizes history instead of dropping it, and re-emits tool results in a form the API accepts — the difference between a session that survives 300 steps and one that dies with a 400 error. The CJK-aware estimator makes pre-send budgeting honest even for non-Latin workloads.

Put together: near-frontier agentic behavior at commodity-model cost. On the official board, the rows around RingZero's 80% are GPT-5.5-class agents; the best official DeepSeek-family entry sits at 39.6%. The gap is the harness, and the harness is small enough to read in an afternoon.

Quick start

Up and running in four steps

# 1. clone & install
git clone https://github.com/abbychau/ringzero
cd ringzero
npm install && npm run build

# 2. link once so `ringzero` works anywhere
npm link

# 3. run
$ ringzero                        # interactive TUI
$ ringzero "prompt"               # one-shot
$ ringzero --watch "prompt"       # re-run on file changes

# 4. verify
$ ringzero --doctor               # environment self-check
